# Приложение «Холодильник»

Программа для контроля содержимого холодильника, управления запасами продуктов, отслеживания их количества и сроков годности. Проект выполнен в рамках учебного модуля по декомпозиции задач на понятные изолированные функции с чётким ТЗ.

## Описание структуры данных

Содержимое холодильника хранится в глобальном словаре `goods`, где:
* **Ключ** — название продукта (строка).
* **Значение** — список словарей, каждый из которых описывает отдельную закупленную партию.

Каждая партия содержит:
* `amount`: количество продукта (`Decimal` для точных расчётов). Может быть целым (для штук, например, яйца) или дробным (для весовых продуктов, например, вода).
* `expiration_date`: дата окончания срока годности (`datetime.date`). Если срок не указан, используется `None`.

### Пример структуры данных:
```python
import datetime
from decimal import Decimal

goods = {
    'Пельмени Универсальные': [
        {'amount': Decimal('0.5'), 'expiration_date': datetime.date(2023, 7, 15)},
        {'amount': Decimal('2'), 'expiration_date': datetime.date(2023, 8, 1)},
    ],
    'Вода': [
        {'amount': Decimal('1.5'), 'expiration_date': None}
    ],
}
```

## Функционал

В модуле реализованы пять основных функций для управления холодильником:

1. **`add(items, title, amount, expiration_date=None)`**  
   Добавляет новую партию продукта в словарь `items`. Если продукт с таким названием уже существует, новая партия дописывается в список.

2. **`add_by_note(items, note)`**  
   Парсит текстовую заметку (строку) свободного формата, преобразует её в структурированные данные и добавляет в словарь. Автоматически извлекает название, количество и дату окончания срока годности.

3. **`find(items, needle)`**  
   Ищет переданную строку (без учёта регистра) в названиях продуктов и возвращает список уникальных наименовастей, в которых есть совпадение.

4. **`get_amount(items, title)`**  
   Считает и возвращает суммарное количество заданного продукта во всех его партиях.

5. **`get_expired(items)`**  
   Проверяет текущую дату и возвращает список продуктов, у которых срок годности истёк.

## Технологии
* **Python 3.x**
* **Модуль `datetime`** для работы с датами.
* **Модуль `decimal`** для исключения погрешностей при операциях с плавающей точкой в количестве продуктов.
